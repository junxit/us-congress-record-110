# MEASURE READ THE FIRST TIME--H.R. 1908

**Speaking:** Reid, Harry (R000146) [D-NV]

**Measures:** H.R. 1908

```
                 MEASURE READ THE FIRST TIME--H.R. 1908

  Mr. REID. Mr. President, I understand that H.R. 1908 is at the desk.
  The PRESIDING OFFICER. The clerk will read the bill by title for the 
first time.

[[Page S11353]]

  The legislative clerk read as follows:

       A bill (H.R. 1908) to amend title 35, United States Code,
```
