# AUTHORITY TO FILE SECOND-DEGREE AMENDMENTS

**Speaking:** Klobuchar, Amy (K000367) [D-MN]

```
               AUTHORITY TO FILE SECOND-DEGREE AMENDMENTS

  Ms. KLOBUCHAR. Mr. President, I ask unanimous consent that 
notwithstanding the provisions of rule XXII, Senators have until 4 p.m. 
Monday, January 28, to file second-degree amendments.
```
