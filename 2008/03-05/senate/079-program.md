# PROGRAM

**Speaking:** Pryor, Mark L. (P000590) [D-AR]

```
                                PROGRAM

  Mr. PRYOR. Madam President, this evening we were able to reach an 
agreement to have a vote in relation to the Vitter amendment regarding
```
