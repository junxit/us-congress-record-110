# PROGRAM

```
                                PROGRAM

  Mr. LEVIN. Mr. President, under a previous order, at 5:30 p.m. on 
Monday, the Senate will proceed to a cloture vote on the motion to

with respect to the FISA legislation. When we return from the Fourth of 
July recess, we will take up the FISA legislation and consider three
```
